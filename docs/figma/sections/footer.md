## Раскладка

- padding: **64 × 165**, контент **1110** (`1440 − 2×165`) — как в
  `updates`, но уже контейнера страницы (1152). Поэтому
  `.footer__inner { max-width: 1158px }` (1110 + 2×24 гуттер
  `.container`);
- группы `Company Info` (350) и `Links` (635) разнесены зазором **125**,
  выровнены по верху (`items-start`);
- 328 = 64 + 200 + 64 — высоту задаёт колонка ссылок (200).
