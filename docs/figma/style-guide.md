## Типографика

Гарнитура — **Inter**, `letter-spacing: 0` везде.

### Headlines

| Стиль | Размер / интерлиньяж | Начертание |
|-------|----------------------|-----------|
| `Headline 1` | 64 / 76 | Semi Bold, 600 |
| `Headline 2` | 36 / 44 | Semi Bold, 600 |
| `Headline 3` | 28 / 36 | **Bold, 700** |
| `Headline 4` | 20 / 28 | Semi Bold, 600 |

### Body

| Стиль | Regular | Medium |
|-------|---------|--------|
| `Body 1` | 18 / 28 | 18 / 28 |
| `Body 2` | 16 / 24 | 16 / 24 |
| `Body 3` | 14 / 20 | 14 / 20 |
| `Body 4` | 12 / 16 | 12 / 16 |

### Расхождение в Headline 3

Подпись на странице `Typography` гласит `Semi Bold, 28/36`,
но переменная `Heading/Headline 3` возвращает:

```
Font(family: "Inter", style: Bold, size: 28,
     weight: 700, lineHeight: 36, letterSpacing: 0)
```

Переменная — то, к чему реально привязан компонент, поэтому
ориентироваться нужно на неё: **700, не 600**.

## Кнопки

Фрейм `Buttons` (`1:658`) — матрица компонентов.

### Варианты

- **Type**: `Primary`, `Secondary`, `Tertiary`
- **Size**: `Normal`, `Medium`, `Small`
- **State**: `Default`, `Hover`, `Focus`, `Disabled`
- **Icon**: `No icon`, `Icon left`, `Icon right`

Имя компонента кодирует всё сразу, например:
`Type=Primary, Size=Normal, State=Default, Icon=No`.

`Tertiary` в секциях страницы не используется — в `index.html`
все шесть кнопок это `btn--primary` и `btn--ghost`.

### Состояния primary-кнопки

Фактические значения в макете:

| Состояние | Значение |
|-----------|----------|
| Default | `#28CB8B` |
| Hover | `#28CB8B` — **визуально не отличается от Default** |
| Focus | `#28CB8B` + `border: 2px solid #4D4D4D` |
| Disabled | `#F5F7FA` |

Hover-эффекта в макете нет: ни тени, ни рамки, ни смены цвета.
Повторяем как есть, свой hover не придумываем без отдельного решения.

### Внутренние отступы

| Кнопка | Padding |
|--------|---------|
| header-кнопки (40 px) | `padding-inline: 20px` — расчётно: 20 + 37 + 20 = 77 |
| кнопки секций (52 px) | `padding: 14px 32px` — измерено на hero `Register` |

### Размеры

| Size | Высота | Ширина без иконки | Ширина с иконкой |
|------|--------|------------------|------------------|
| Normal | 56 | 111 | 143 |
| Medium | 48 | 106 | 130 |
| Small | 32 | 84 | 108 |

Icon-only кнопки квадратные: 64, 48, 32.

Ссылки (`Link`): Normal 47×24, Medium 42×20, Small 36×16.

### Важно: кнопки на странице не из набора

Высота кнопок в макете **52 px** (hero 128×52, case-study 151×52,
cta 178×52), а в наборе есть только 56 / 48 / 32. Значит кнопки
на странице растянуты вручную и набора не касаются.

Header-кнопки — **40 px** (Login 77×40, Sign up 91×40), тоже
не из набора.

Горизонтальные отступы header-кнопок: Login `20 + 37 + 20 = 77`,
Sign up `20 + 51 + 20 = 91` → **`padding-inline: 20px`**.

## Чего нет в этой выгрузке

Квота Figma MCP на плане `starter` закончилась, поэтому через
`get_design_context` снять не удалось часть свойств. Реестр всех
пробелов и принятых по ним решений — в `gaps.md`.

Часть пробелов закрыта вручную: радиусы, тени, padding кнопок,
состояния кнопок, структура футера, названия пунктов меню.

Что осталось неподтверждённым:

- стиль числа в `achievements` и стиль заголовка карточки в `updates`
  — не различаются по высоте строки, нужен `get_design_context`;
- цвета секций, кроме `community` — `get_variable_defs` вызывался
  только для `14:1010`;
- типографика и цвета футера — экземпляр компонента `get_metadata`
  не раскрывает;
- геометрия мобильной версии — фрейм `212:813` найден, но не разобран.

Подробнее — `gaps.md`, раздел «Открытые пробелы».
