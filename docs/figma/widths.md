# Горизонтальные размеры секций

Сводка: где в макете жёсткие ширины, где центрирование, где остаётся
свободное поле. Нужна, чтобы не гадать про `max-width` при вёрстке.

| Секция | Контейнер | Поля слева/справа | Текстовая ширина |
|--------|-----------|--------------------|------------------|
| header | 1200 | 120 | 1200 (меню 588, Login 182) |
| hero | 1152 | 144 | 657 + 104 + 391 |
| clients | 1152 | 144 | 1110 |
| community | 1440 | 0 (текст 542 по центру) | 542 заголовок / 1440 описание / 3×299 карточки |
| case-study | 1152 | 144 | 601 текст, картинка 442 |
| achievements | 1152 | 144 | 540 заголовок / 540 счётчики |
| guide | 1152 | 144 | 601 текст, картинка 441.53 |
| customers | 1152 | 144 | 748 текст / 326 фото |
| updates | 1440 (фрейм 1110) | 165 | 1110 / 628 описание / 3×368 карточки |
| cta | 1440 | 276.5 | 887 |
| footer | 1440 | — | компонент |

## Выводы

1. **Общего правила ширины нет.** Текст бывает 601, 657, 748, 887.
   Ограничение на 1152 — это ширина секции-обёртки, а не текста.
2. **1152 = 1200 − 48.** Универсальный контейнер
   `max-width: 1200px` + `padding-inline: 24px` покрывает все секции,
   кроме header (свои 1200/120) и тех, где текст шире 1152
   (community-описание 1440, cta 887 внутри 1440, updates-описание).
3. Для центрированных коротких текстов (`h2` 1110, описание 628)
   `text-align: center` даёт тот же результат, что и бокс фиксированной
   ширины, и не требует обёрток.
4. community и updates симметричны: описание центрируется, заголовок —
   либо в боксе 542, либо во всю 1110. Оба варианта сводятся к
   `text-align: center`.
