# Выгрузка макета из Figma

Эта папка — локальная копия спецификации макета, снятой через Figma MCP
`2026-10-01`. Нужна потому, что квота Figma MCP на бесплатном плане
(`starter`) ограничена, а значения из макета требуются постоянно.

## Источник

- Файл: `https://www.figma.com/design/l9442HdlZ9xWUYbsxcLbuW/01-nexcent-landing`
- `fileKey`: `l9442HdlZ9xWUYbsxcLbuW`
- Страница `Design` (canvas `0:1`) → фрейм `Landing Page` = `5:573`,
  1440×4376
- Страница `Style Guide` = `1:2`

## Правило использования

1. Сначала читать значения отсюда.
2. Перед вёрсткой секции проверить `gaps.md` — часть свойств
   не подтверждена и берётся по решению, а не из макета.
3. Обращаться к Figma MCP только если макет изменился
   (пользователь сказал об этом прямо).
4. После каждого изменения макета обновлять соответствующий файл здесь.

## Содержимое

| Файл | Что внутри |
|------|------------|
| `gaps.md` | реестр пробелов выгрузки: что не удалось снять, как закрыто, что открыто |
| `page-structure.md` | порядок секций, высоты, промежутки между ними |
| `style-guide.md` | типографика, цвета, кнопки, радиусы, тени, контейнер |
| `sections/*.md` | геометрия, типографика и цвета по каждой секции |

## Ограничения выгрузки

- Скриншоты не сохранялись: AI не имеет визуального входа,
  запросы к MCP делались с `excludeScreenshot: true` — экономия квоты.
- Векторные слои иллюстраций (сотни `Vector` внутри `mobile-login/*`)
  в спецификацию не попали: это растровые ассеты, уже выгруженные в `img/`.
- Числа в макете местами дробные (`433.3990173339844`,
  `3147.39892578125`) — это следствие figma-экспорта шаблонов,
  округляются до целых.

## Как переснять

```
get_metadata(fileKey, nodeId)                     — геометрия, дёшево
get_design_context(fileKey, nodeId,
                   excludeScreenshot: true)       — цвета, типографика, тени
```

`get_variable_defs` требует выделенного слоя в desktop-приложении Figma
и по `nodeId` не работает.
